رفع Selin إلى Cloudflare بدون GitHub
====================================

1) فك ضغط المشروع في مجلد عادي على الكمبيوتر.
2) ثبّت Node.js إصدار LTS إذا لم يكن مثبتًا.
3) افتح ملف deploy-cloudflare.bat.
4) ستفتح صفحة Cloudflare في المتصفح: سجّل الدخول إلى الحساب المطلوب ووافق على الربط.
5) ستظهر بيانات الحساب داخل النافذة. تأكد أنه الحساب الصحيح ثم اضغط أي زر.
6) انتظر حتى يكتمل البناء والنشر.
7) انسخ رابط workers.dev الذي يظهر في النهاية.

مهم:
- لا تستخدم Upload your static files، لأن Selin تطبيق Next.js يحتاج Build.
- ملف .env.local يحتوي فقط على Supabase Project URL وPublishable Key المستخدمين في الواجهة.
- لا تضع أي Service Role Key أو sb_secret_ داخل المشروع.
